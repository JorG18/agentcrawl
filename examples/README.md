# AgentCrawl examples

These examples mirror the workflows linked from [docs/EXAMPLES.md](../docs/EXAMPLES.md).

| Example | Use when |
| --- | --- |
| [cli_scrape.md](cli_scrape.md) | You have one accessible URL and want Markdown from the terminal. |
| [python_scrape.py](python_scrape.py) | You want to call AgentCrawl from Python code. |
| [api_scrape.md](api_scrape.md) | You run AgentCrawl as a self-hosted HTTP API. |
| [docker.md](docker.md) | You want the API through the published GHCR image. |
| [mcp.md](mcp.md) | You want an agent client to use AgentCrawl tools. |
| [browser_rendered.md](browser_rendered.md) | A page needs local JavaScript rendering. |

Use `https://pypi.org/project/agentcrawl-ai/` for normal smoke examples. Keep `https://example.com` for boundary/challenge documentation only.
